# Event Horizon

Der **50%-Punkt zwischen zwei gestackten Liquidity Pools** (z.B. zwei Sellside-Pools). Dient als
Entscheidungs- und Partial-Profit-Marker:

- Wird der erste Pool erreicht, können dort bereits **Teilgewinne** mitgenommen werden.
- Closed Preis **unter** (bzw. über, spiegelbildlich) dem Event Horizon, steigt die
  Wahrscheinlichkeit deutlich, dass auch der **zweite Pool** erreicht wird — der Event Horizon
  selbst eignet sich ebenfalls als weiterer Partial-Punkt.
- Wird auch genutzt, nachdem ein klarer [[AMD Cycle (Accumulation – Manipulation – Distribution)|DOL]]
  bereits erreicht wurde, um bei einem Best-Case-TP-Szenario noch zusätzliche Partials zu sichern.
